# SorhyAI  
**Персональный ИИ-бот с характером.**  
Работает на базе Cypher Alpha.  
Отвечает естественно, запоминает контекст, не тупит.  

---

### Возможности:  
- 🧠 Естественный диалог  
- 🌍 Переводы и улучшения текста  
- 💬 Telegram-интерфейс  
- ⚙️ Кастомное ядро и память
